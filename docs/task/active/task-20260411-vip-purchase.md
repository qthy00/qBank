## 需求描述

当前项目缺少VIP购买页面，需要设计并实现该页面，接口先用模拟数据替代。

### 业务背景
用户需要购买VIP会员来获取更多功能和特权，包括无限制访问题库、下载文档、去除广告等权益。

### 功能目标
- [ ] 展示VIP会员套餐列表（月卡、季卡、年卡等）
- [ ] 展示VIP会员权益说明
- [ ] 支持选择套餐并进行购买
- [ ] 展示当前用户VIP状态
- [ ] 提供支付方式选择

### 约束条件
- 使用模拟数据替代真实接口
- 遵循项目现有代码规范
- 使用Element Plus组件库
- 样式使用px单位
